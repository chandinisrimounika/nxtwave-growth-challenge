# 🚀 NxtWave Growth Challenge: AI Workshop Campaign

Welcome to the repository for the **NxtWave Growth Intern – Growth Challenge**! 

This project contains the working asset (a dynamic landing page) built to support a strategic growth campaign. The mission is to drive 500 final-year engineering students to register for a free online workshop: *"Build Your First AI Project in 60 Minutes"* using a ₹2,000 budget and a 7-day timeline.

## 🔗 Live Demo
**Test the live landing page here:** [Live Prototype](https://chandinisrimounika.github.io/nxtwave-growth-challenge/)

---

## 🎯 The Growth Strategy (Overview)
Instead of relying on expensive, low-conversion paid ads, this campaign utilizes a **Referral-Led Growth Loop**. 
* **The Hook:** A free, 60-minute hands-on AI project tailored for final-year students looking to build their resumes.
* **The Engine:** Students receive a unique referral code upon registration. They are incentivized to share this code in their college WhatsApp groups to climb a live leaderboard.
* **The Reward:** Top 3 ambassadors win exclusive NxtWave prizes (Mentorship, Pro Access, Swag).

## ✨ Features of the Working Asset
This landing page is the core conversion engine of the campaign. It includes:
1. **Dynamic Registration Form:** Client-side validation ensuring only complete, accurate data is submitted.
2. **Referral Growth Loop:** Users can input a friend's referral code, directly impacting the gamified leaderboard.
3. **Live Leaderboard:** A real-time ranking of top student ambassadors to drive competitive sharing (gamification).
4. **Scarcity & Urgency Drivers:** 
   * A live, ticking seat counter (e.g., "348 seats remaining").
   * Dynamic pop-ups showing recent registrations (e.g., "👋 Harsha K just registered from Amrita!") to build social proof and FOMO.
5. **Mobile-First Design:** Fully responsive and optimized for students opening the link directly from WhatsApp on their smartphones.

## 🛠️ Tech Stack
This project is built using a lightweight, fast, and dependency-free stack:
* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Custom styling, flexbox/grid layouts, and smooth animations.
* **JavaScript (Vanilla):** DOM manipulation, form validation, dynamic pop-up sequencing, and leaderboard logic.
